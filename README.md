## 📚 Lessons

<div align="center">

<img src="https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/electronics-learning-platform/main/docs/screenshots/lessons.png" width="90%">

</div>

The learning system is organized into progressive electronics modules.

Students move through concepts sequentially instead of receiving an unstructured collection of topics.

### Current curriculum

| Module | Topic |
|---|---|
| 01 | Electricity, Voltage & Current |
| 02 | Resistance & Ohm's Law |
| 03 | Resistors & LED Circuits |
| 04 | Capacitors |
| 05 | Diodes & LEDs |
| 06 | Transistors & Switching |
| 07 | Sensors & Inputs |
| 08 | Basic Automation |

Lessons are progressively unlocked as the learner completes the required previous content.

# 🧪 Challenges

<div align="center">

<img src="https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/electronics-learning-platform/main/docs/screenshots/challenges.png" width="90%">

</div>

The Challenges system converts concepts into active problem-solving.

Challenge types include:

- Conceptual questions
- Numerical problems
- Circuit-based problems
- Troubleshooting
- Component identification
- Application-based questions
- Electronics calculations

Numerical questions can include circuit diagrams with labelled:

- Voltage
- Current
- Resistance
- Component values
- Connections
- Relevant nodes

The goal is to connect:

**Theory → Formula → Circuit → Calculation → Understanding**

# 🔌 Circuit Designer

<div align="center">

<img src="https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/electronics-learning-platform/main/docs/screenshots/circuit-designer.png" width="90%">

</div>

The Circuit Designer is an educational schematic-building environment designed to introduce beginners to electronic circuit construction.

It is inspired by the general workflow of professional electronic design tools while intentionally remaining simpler and more approachable for students.

## Features

- Component library
- Component search
- Component categories
- Circuit canvas
- Grid
- Snap-to-grid
- Zoom
- Pan
- Full-screen workspace
- Component placement
- Component movement
- Component rotation
- Component deletion
- Wire connections
- Connection points
- Component properties
- Undo / Redo
- Circuit validation
- Educational error messages

### Component categories

#### Basic Components

- Resistor
- Potentiometer
- Variable resistor
- Capacitor
- Polarized capacitor
- Inductor

#### Semiconductors

- Diode
- LED
- Zener diode
- NPN transistor
- PNP transistor
- MOSFET
- Voltage regulator

#### Inputs & Outputs

- Push button
- Switch
- Toggle switch
- LDR
- Thermistor
- IR sensor
- Ultrasonic sensor
- Buzzer
- Speaker
- Motor
- Servo motor
- Relay
- 7-segment display
- RGB LED

#### Power

- Battery
- DC voltage source
- VCC
- GND

#### Digital Logic

- AND
- OR
- NOT
- NAND
- NOR
- XOR
- 555 Timer
